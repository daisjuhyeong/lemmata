법적 부담과 오탐이 낮은 구조를 처음부터 골랐습니다. 오탐은 근거 없는 지적을 내보내지 않는 규칙에 더해, 내용 해시로 출력이 실제로 바뀐 경우만 알리고, 커밋 메시지가 출력 불변이라고 말하는 경우는 낮은 신뢰도로 구분합니다. 원고는 저자 PC의 앱에서만 처리하고 서버에 저장하지 않습니다. 학회 정책상 리뷰어가 제출물을 LLM에 올리는 것은 금지되어 있어 저자 본인의 원고만 다룹니다. 저작권은 저자 원고와 오픈 액세스 원문만 씁니다. 한국 AI 기본법에서는 고위험 영역이 아니고 제31조의 고지와 표시 의무만 지키면 됩니다. 앱은 구독 로그인으로 Claude를 부르지 않고, AI는 사용자 자신의 Claude Code나 API 키로 실행합니다. Overleaf Git 연동은 유료 기능이라 로컬 폴더와 zip 업로드도 지원합니다. 1인 범위는 CTO 에이전트가 관리합니다.
