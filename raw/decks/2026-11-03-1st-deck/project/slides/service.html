왜 앱인가

저장소, LaTeX, 서버 결과가 PC에 있음. 미공개 원고가 PC 밖으로 나가지 않음. Tauri 설치본 약 8.6MB (Electron 244MB)

지켜야 할 조건

제3자 앱은 Claude 구독 로그인 제공 불가 → AI는 사용자 Claude Code나 API 키로. Overleaf Git은 유료 기능 → 폴더, zip도 지원

서비스 형태는 데스크톱 앱입니다. 코드 저장소와 LaTeX 폴더, 서버에서 받은 결과가 모두 연구자 PC에 있고, 미공개 원고를 서버로 보내고 싶지 않기 때문입니다. 앱은 Tauri로 만들어 가볍게 하고 Mac부터 시작합니다. 모든 상태는 연구 저장소 안 .lemmata 폴더에 git으로 남기 때문에, 어떤 OS나 어떤 에이전트를 써도 같은 기록을 봅니다. AI 점검은 사용자가 자기 Claude Code에서 플러그인으로 돌립니다. 제3자 앱이 Claude 구독 로그인을 제공하는 건 약관상 안 되기 때문입니다. Overleaf Git 연동은 유료 기능이라 폴더나 zip으로도 받습니다.
