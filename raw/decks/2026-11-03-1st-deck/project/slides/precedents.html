혼자서 에이전트로 서비스를 만드는 게 현실적인지 선례를 찾아봤습니다. Anthropic이 소개한 YC 스타트업 세 곳입니다. Ambral은 엔지니어가 한 명인데 서브에이전트로 조사하고 Opus로 계획, Sonnet으로 구현을 나눠 씁니다. Vulcan은 창업자 대부분이 개발자가 아니었지만 여러 Claude Code 인스턴스에 일을 맡기고 검수하는 방식으로 넉 달 만에 시드 투자를 받았습니다. HumanLayer는 플랫폼 전체를 Claude Code로 만들었습니다. 제 서비스에 적용하면 플러그인 배포와 사용자 플랜 실행은 바로 가능하고, 호스팅은 API 키로 가야 하며, 이미 있는 무료 리뷰 스킬과는 변경 추적과 측정한 정밀도로 차별화해야 합니다.
