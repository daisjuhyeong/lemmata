로컬 LLMClaude Code 에이전트
무엇의 문제추론을 어디서 하나모델 + 도구 + 반복 루프
동작한 번 답하고 끝실행, 관찰, 수정을 끝까지 반복
파일, 셸스스로는 못 함직접 읽고 실행
긴 작업7–14B: 긴 문서 누락, 규칙 이탈여러 단계에 걸쳐 규칙 유지

왜 로컬 LLM이 아니라 Claude Code 에이전트를 쓰는지 말씀드리겠습니다. 로컬 LLM은 추론을 어디서 하느냐의 문제이고, 에이전트는 모델에 도구와 반복 루프를 붙인 구조입니다. 로컬 LLM은 질문에 한 번 답하고 끝나지만, 에이전트는 파일을 읽고 명령을 실행하고 결과를 보고 다시 고치는 과정을 끝까지 합니다. 제 서비스는 긴 원고와 저장소를 정확히 읽고 규칙을 지켜야 하는데, 7에서 14B 로컬 모델은 여기서 누락과 규칙 이탈이 쌓였습니다. 그래서 Mac mini는 모델을 돌리지 않고 에이전트가 일하는 사무실 역할만 하고, 로컬 모델은 인터뷰 익명화 같은 좁은 일에만 씁니다.
