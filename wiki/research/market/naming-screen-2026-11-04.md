## Deep-screen notes (survivors)

### 1. Antecedo (안테세도)
- Namespaces: PyPI `antecedo` free (client error); GitHub user https://github.com/antecedo exists, 2 followers, no repos (could be contacted or worked around with an org like `antecedo-dev`). npm unverified.
- Trademark: general searches for "Antecedo" returned only near-misses (ANTECO, ANTEC, ANTECE, ANTEDOTUM, ANTEVORTA via markinton/justia/trademarkdir, secondary sources). No exact hit found; classes 9/42 not checked in a primary database.
- Companies: no Crunchbase/LinkedIn/Tracxn hit surfaced in search.
- Korean: 안테세도 is pronounceable, but the last two syllables "세도" are a known Sino-Korean word (勢道, 세도정치, "power-wielding politics"); "안테" echoes 안테나. Mild, not offensive; ask a Korean-speaking friend. Alternative spelling 안테케도 (closer to Latin /k/) avoids "세도".
- Meaning fit: "the thing that goes before" maps directly to upstream dependency. Short enough (4 syllables English: an-te-ce-do), a bit long for CLI.
- Domains: antecedo.com/.ai/.app: search showed no live site; availability unverified.

### 2. Stemmal (스테말)
- Namespaces: PyPI and GitHub appear free. npm unverified.
- Conflicts: no exact company/product hit; neighbours: Stemma (marks), Stem Inc., Stemline Therapeutics.
- Weakness: meaning obscure outside philology; may read as typo of "stemmal" / "stem".

### 3. Originis (오리지니스)
- Namespaces: PyPI free; GitHub user `originis` exists with no public repos.
- Conflicts: ORIGENIS (EU 79283535, pharma, secondary source trademarkdir), Origis (energy). Likely different classes but phonetically close.
- Weak distinctiveness ("origin" is descriptive/crowded in AI).

### Eliminated after namespace/company check
Stemmata, Tekmeria, Vestigia, Provena, Veritrail (PyPI exact-name packages, several in the same evidence/provenance space); Veritrace, Vestigo, Filum, Proveno/Provenio, Tracerly, Evidens, Tracta, Stemma (companies/marks).

## Recommended top 3
1. **Antecedo** - best semantic fit (what comes before = upstream dependency), no commercial conflict found; fix the Hangul spelling and take the GitHub org.
2. **Originis** - provenance/origin meaning, free on PyPI; weaker distinctiveness and phonetic closeness to ORIGENIS.
3. **Stemmal** - clean namespaces and a lineage-tree etymology; meaning is obscure and the mark is close to "Stemma".

Honest caveat: only three of ~20 candidates survived quick screening, and none is strong. If none appeals, the next step is a fresh batch of fully invented (non-Latin-root) names, since Latin evidence/provenance roots are heavily used by 2026 AI-provenance packages. Needs Juhyeong's decision; before adoption run live USPTO/KIPRIS/WIPO searches and a domain check.
