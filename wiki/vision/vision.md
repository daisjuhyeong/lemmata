# Vision
Lemmata (working name): before you submit, before the reviewer reads it. An AI pre-reviewer that checks a paper's main text, appendix and references against each other, with evidence for every finding.
- First user: authors, pre-submission (own paper only; no reviewer features).
- Runtime: open-source Claude Code plugin on the author's own Claude plan; public gallery of reports on arXiv papers.
- Principle: never writes the science; shows evidence, the author decides.
