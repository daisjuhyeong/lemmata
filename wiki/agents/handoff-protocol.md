# Handoff protocol
1. Task card in wiki/sprints/Sxx/ (goal, inputs, acceptance criteria, owner, reviewer, done when).
2. Owner works on a feature branch, ends with a handoff note (what changed, open questions, links).
3. QA verifies independently; no note = not done.
4. CTO recommends; Juhyeong approves merges, ADRs, publishing and spending.
